# ForeverSVFix v1.0.2

v1.0.2 reduces the automatic update-check cache from 24 hours to 15 minutes.

This means ForeverSVFix will notice newly released updates much sooner while still avoiding repeated GitHub requests when the app is opened many times in a short period.

Manual **Check for updates** checks remain immediate and bypass the cache.

There are no changes to the SavedVariables workaround in this release.
