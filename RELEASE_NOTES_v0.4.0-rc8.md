# ForeverSVFix v0.4.0 RC8

Packaging release candidate.

Changes from RC7:

- Add a Linux x86_64 AppImage build.
- Make the AppImage the recommended Linux download.
- Keep the raw Linux standalone executable as a fallback.
- Make the AppImage launch the console menu in a terminal when started from
  common Linux desktop environments.
- Add an AppImage-specific beginner note to the README.
- Keep Windows x64, macOS Intel, and macOS Apple Silicon standalone builds.
- Keep the validated SavedVariables workaround unchanged.

Validated in-game on Linux/Wine with WoW Forever 1.60.1.
Windows and macOS remain experimental until native users test them.
